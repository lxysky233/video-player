# Video Player

一个开源的 Windows 桌面短剧播放器。单窗口完成「发现 → 搜索 → 选集 → 播放 → 追更」全流程，绿色便携，解压即用。

- **版本**：1.0.0
- **平台**：Windows 10 / 11（x64）
- **技术栈**：Flutter 3.47（界面） + Go 原生核心（网络与下载） + libmpv / ffmpeg（解码）
- **许可**：GPL-3.0
- **仓库**：[GitHub](https://github.com/lxysky233/video-player) · [Gitee](https://gitee.com/lxysky233/video-player)

## 快速开始

1. 解压发布包，双击 `VideoPlayer.exe`。
2. 首次启动会显示使用条款，勾选同意后进入首页。
3. 想固定到桌面：右键 `VideoPlayer.exe` → **发送到 → 桌面快捷方式**。

无需安装、无需额外运行库、无需账号。首次联网时会自动注册设备并拉取站源目录。

**首次启动只有「红果」和「红果全集版」两个站源**。其余 23 个站源随包放在 `src\data\bundled\`，打开 👤 → 模块 → **内置**，点任意一项的「安装」即可离线装上（无需联网、无需在线仓库）。装好后再点顶栏 🌐 就能切换。

站源面板展示的数量，就是你上次启用的数量：关掉的站源不会自己回来，开启的也不会自己消失（包括 NSFW 分组）。

## 播放页操作

鼠标移入画面后，底部浮出控制条；静止数秒自动淡出。

```
⏮  ▶  ⏭   00:32 / 01:28   [弹幕]        自动（1080P）  1.0x  [比例][🌙][🔊][画中画][投屏][宽屏][⛶]
```

- **进度条**：拖动跳转；悬停显示时间刻度。
- **清晰度 / 倍速**：悬停弹出选项面板，选择后立即切换。
- **音量**：悬停喇叭弹出竖直音量条，拖动调整；单击喇叭静音 / 取消静音；画面内滚动滚轮也可调音量。
- **画面比例**：自动 / 拉伸 / 裁切 / 等宽 / 等高 / 原始 / 4:3 / 16:9。
- **宽屏**：切换「左视频、右选集」的双栏布局。
- **选集面板**：右侧可滚动翻页；点集号立即切集，点右上角箭头进入全屏。
- **播放页右上角**只有下载入口；追剧（收藏）只在详情页提供，避免误触。

## 便携使用

`userdata\` 是所有可变状态的唯一位置，不写注册表、不写 `AppData`。

**迁移 / 备份**：关闭程序 → 复制整个文件夹 → 在新机器双击 `VideoPlayer.exe`。

**恢复出厂设置**：关闭程序 → 删除 `userdata\` 整个目录 → 重新启动。程序会自动重建 `userdata\` 并写回默认配置（首次启动只装红果与红果全集版，其余 23 个在模块页「内置」里等着一键安装）。

**注意**：便携模式靠 exe 同级的 `userdata\` 目录识别。目录不存在时程序会自己补建，所以直接删掉整个目录也能回到出厂状态；但请确保 exe 所在目录可写，否则状态会落到 `%LOCALAPPDATA%`。

**分发时的默认配置**：发布包里的 `userdata\` 是空的。程序第一次启动时写入默认设置、单用户档案，并从 `src\data\bundled\` 安装「红果」与「红果全集版」两个模块、把 25 个站源全部登记为「仅这两个开启、其余关闭」，不含任何观看记录、缓存、登录凭证与下载内容。默认设置（弹幕 70% 四分之一屏不加粗、点开即播、后台播放、下载含 VIP 集、同时下载 5 个按站源分类、主题白色、老板键 `Ctrl+Alt+D`）写在代码里，见 `src\scripts\set_defaults.py`。

## 站源分级与红果全集版

### 站源分级

25 个站源按内容分级，每个模块的 `manifest.json` 里用 `group` / `groupName` 标注：

| 分级 | 数量 | 首次启动状态 | 站源 |
| --- | --- | --- | --- |
| 大众级 | 12 | 红果、红果全集版开启，其余在模块页「内置」待安装 | 红果、红果全集版、无尽影视、魔都影视、百度影视、非凡影视、360影视、光速影视、鬼片、韩小圈、爱看机器人、青空 |
| NSFW · 限制级 | 13 | 全部关闭 | 笔盒、潮流AV、帝果、Hanime1、黑桃、黄豆、黄果旧版、黄果视频、黄果 AI、剧果、禁果短剧、MissAV、野果 |

限制级站源首次启动不装也不开，首页不会出现成人内容。需要时打开 👤 → 模块 → **内置**，找到对应站源点「安装」并开启；设置 → 代理 里的「站源代理」也按这两个分组排列。

程序不会自动开关站源：装了什么、开了几个，下次启动就还是几个，NSFW 分组同样按你自己的选择保留。

### 红果全集版

红果本体第 6 集起需要账号权益，客户端拿不到。**红果全集版**是独立的站源，解决这个问题：

- **剧库仍来自红果** —— 首页分类（真人剧 / 漫剧 / AI 剧）、详情页、选集列表、搜索联想全部取自红果网页端，剧集信息、封面、简介与红果一致。
- **片源来自采集站** —— 播放时不向红果要流，而是按剧名到 魔都影视 / 无尽影视 / 360影视 / 百度影视 / 光速影视 依次匹配，取回该剧的完整播放列表。
- **自动按集切分** —— 采集站多数把整季压成一条「全集」长片（常见 4,000 段、8,000 秒以上）。模块会拉回完整 playlist，按 `总时长 ÷ 总集数` 均分切片，只把第 N 集对应的那段交给播放器。选集列表里每一集都是独立条目，可点播、可拖动、可连播。
- **集数以片源为准** —— 若片源标注的集数（如 `vod_remarks: 全87集`）与红果不同，按片源集数切分，避免错位。

用法：顶栏 🌐 → 选 **红果全集版** → 浏览或搜索 → 进入详情 → 选集播放。

**匹配不到片源时**会提示「片源站没有找到《剧名》，换个剧源或稍后再试」。红果剧库比采集站新，个别新剧、短季或改名剧确实没有对应片源，此时可换用其它站源，或等采集站收录后再试。

## 常见问题

**首次启动为什么只有两个站源**
发布包不预装全部站源：程序第一次启动时只从 `src\data\bundled\` 装上红果与红果全集版并启用它们，其余 23 个留在 👤 → 模块 → **内置**，点「安装」即离线装上（不联网、不走在线仓库）。这样首页干净，也不会默认打开限制级内容。

**站源面板里少了几个站源**
面板只列「已安装且已开启」的站源，数量和上次关闭程序时一致。要找回被关掉的：👤 → 模块 → 已安装，把开关打开；要装新的：👤 → 模块 → 内置。

**搜索一直显示「正在搜索」**
站源响应慢或网络不通。检查 设置 → 代理，或换时间重试。

**提示「暂时无法播放」**
通常意味着站源侧的取流接口变更或被临时限制。模块化站源的取流逻辑写在 `userdata\modules\<源名>\main.js` 中，可等待模块更新（👤 → 模块 → 检查更新），或切换到其它站源。

**红果站源只能看前 5 集**
红果对每部剧下发 `accessible_episode_cnt: 5` 与 `pcAuthenticatedPlayback: false`，第 6 集起的 `play-info` 与 `fallback-play-info` 一律 403，这是服务端权益判定，客户端改任何请求头或参数都不生效。想看整部剧请切到 **红果全集版**（见 [站源分级与红果全集版](#站源分级与红果全集版)）。

**「全集」只有一集，没有分集按钮**
采集类站源把整季压成一条长片（常见 700+ 集、总时长 10 小时），选集列表里就只有「全集」一项，用进度条拖动定位。

**画面上只有声音没有画面**
HEVC 硬解失败。打开 设置 → 播放 → 解码方式，从「默认」改为「兼容」，重新打开该集。

**下载任务不动**
并发过高会被站源限流。设置 → 下载 里把并发降到 2～3。

**改了背景颜色没变化**
本版本已移除上游的「跟随系统取色」开关，色板选择立即生效。若仍显示旧配色，关闭程序再启动一次（配置写在 `userdata\store\settings.json` 的 `themeColor`）。

**窗口不见了 / 关不掉**
如果设过老板键，按一下即可恢复。也可在设置 → 播放 → 窗口置顶 关闭置顶后再寻找窗口。

## 从源码构建

### 依赖

- Flutter 3.47（Dart 3.13）
- Visual Studio 2022 的「使用 C++ 的桌面开发」组件
- Go 1.26（仅在需要重新编译 `duanju_core.dll` 时，需搭配 MinGW-w64 提供 `CGO_ENABLED=1` 的 C 工具链）

国内网络先设置镜像（PowerShell）：

```powershell
$env:PUB_HOSTED_URL='https://pub.flutter-io.cn'
$env:FLUTTER_STORAGE_BASE_URL='https://storage.flutter-io.cn'
```

### 完整构建

```powershell
cd src
flutter pub get
flutter build windows --release
```

产物位于 `src\build\windows\x64\runner\Release\`，其中包含 `VideoPlayer.exe`、运行库与 `src\data\`。

### 只改界面（无 C++ 工具链亦可）

`flutter assemble` 可以只编译 Dart AOT 快照，不触碰 C++ 侧：

```powershell
cd src
flutter assemble -dTargetPlatform=windows-x64 -dBuildMode=release `
  --output=<绝对路径>\build\out release_bundle_windows-x64_assets
```

把 `build\out\windows\app.so` 覆盖到 `src\data\app.so`，`build\out\flutter_assets\` 覆盖到 `src\data\flutter_assets\`，`VideoPlayer.exe` 与各 DLL 保持不动即可。

> 运行时资源目录由 exe 内的宽字符串决定，已用二进制补丁指向 `src\data`；因此 `src\data` 必须与 `VideoPlayer.exe` 保持同级目录下的 `src\data` 结构，不能单独挪走。
>
> 补丁本身是两处字节改动，已固化成 `src\scripts\patch_data_path.py`：`VideoPlayer.exe.orig` 是未打补丁的原件，`python src\scripts\patch_data_path.py` 重新生成，`--check` 只校验。手上有新编译的 `VideoPlayer.exe` 时，先把它复制成 `src\scripts\VideoPlayer.exe.orig` 再跑一次即可。原因是 MSVC 把 `DartProject(L"data")` 的 `std::wstring` 长度常量折叠成 4，只改字符串不管用，必须同时把 `0x855c` 处的 `mov r8d,4` 改成 `mov r8d,8`。

### 代码检查

```powershell
cd src
dart analyze lib
```

> 用 `dart analyze` 而不是 `flutter analyze`：后者会去解析插件目录里的符号链接，未开启 Windows「开发者模式」时会直接报错退出。

### 更新内置站源包

`src\data\bundled\` 里的 25 个模块包由脚本生成，源是 `userdata\modules\` 下已安装的模块目录：

```powershell
python src\scripts\make_bundled.py
```

脚本会为每个模块写 `src\data\bundled\<id>.zip`（内部结构 `<id>\manifest.json` + `<id>\main.js`），并汇总出 `src\data\bundled\index.json`。改了某个模块的 `main.js` 之后重跑一次，再重新打包发布即可。

### 打便携包

```powershell
python src\scripts\package_portable.py
```

产物在 `src\dist\video-player-<版本>-win64.zip`，内容为主程序、运行库、`src\data\`、`src\data\bundled\` 与一个空的 `userdata\`，不含源码与任何本机用户数据。

### 压缩体积

发布包里的二进制已经过 UPX 压缩与字体裁剪，可用脚本复现：

```powershell
python src\scripts\shrink_binaries.py all
```

它做三件事：删掉 6 个确认无用的孤儿 DLL、把 `MaterialIcons-Regular.otf` 裁到只保留实际用到的字形（1.6 MB → 27 KB）、对 33 个可安全压缩的 PE 文件跑 `upx --best --lzma`。整套下来安装目录从 235 MB 降到 107 MB，便携 zip 从 92 MB 降到 69 MB，功能不受影响。

以下文件**不能**压缩，脚本已排除：`flutter_windows.dll`（压后启动无窗口）、`libstdc++-6.dll`（单独压缩即启动无窗口）、`libffmpegkit.dll`（UPX 报 `duplicate relocs`）、`concrt140.dll` / `msvcp140*.dll` / `vcruntime140*.dll`（MSVC 运行库，UPX 无法处理）。`src\data\app.so` 是 Flutter AOT 快照，没有 `DT_INIT`，同样无法压缩。`icudtl.dat` 删除后程序无法启动，必须保留。

压缩前务必先退出程序，否则 UPX 会因文件被映射占用而报 `Permission denied`，但标准输出仍会打印压缩比，容易误判为成功。
